 Built a Vendor Performance Analytics Dashboard in Power BI  here's why it matters.

Most recruitment teams manage multiple staffing vendors with zero comparative visibility. Decisions get made on gut feel instead of data.

This dashboard changes that.

Key Metrics Tracked (per vendor, per week):
• Requisitions Assigned → CVs Submitted → Joinees (full funnel)
• Avg Turnaround Time (TAT)
• CV Quality Score
• Hiring Manager Feedback Score
• Offer Acceptance Rate & Dropout Cases

Features:
→ Vendor & Week slicers for dynamic filtering
→ KPI cards: Top Vendor, Best TAT, Avg Quality Scores
→ Vendor Performance Scorecard (full comparison table)
→ Joinee trend line chart (weekly view)

The business value: TA leaders can now make data-backed decisions on vendor allocation, performance improvement, and contract renewals — in seconds, not days.

Tools: Power BI | DAX | Data Modeling
